# PicScreen — Descargas

**PicScreen** deja tus imágenes flotando encima de juegos y aplicaciones en Windows 10/11:
perspectiva, recortes con vértices, captura de pantalla, modo juego y una tecla para mostrar u ocultar cada imagen.

🌐 **Web:** https://picscreen.app

## Descargar
- ⭐ **Microsoft Store (recomendado):** https://apps.microsoft.com/detail/9P0XQR2FL821
- 💾 **Instalador:** [PicScreen-Setup.exe](https://github.com/mrsandia/PicScreen-releases/releases/latest/download/PicScreen-Setup.exe)
- 📦 **Portable:** [PicScreen-Portable.zip](https://github.com/mrsandia/PicScreen-releases/releases/latest/download/PicScreen-Portable.zip)

Todas las versiones y sus novedades están en [Releases](https://github.com/mrsandia/PicScreen-releases/releases).

> Si Windows muestra el aviso de SmartScreen al usar el instalador, pulsa **Más información → Ejecutar de todas formas**.
> La versión de la Microsoft Store no muestra este aviso.

## Apoyar
PicScreen es gratis y sin anuncios. Si te sirve, puedes invitarme un café: https://ko-fi.com/picscreen
